# 政企园区 V2 前端交付包

包含 V2 多业务首页、企业服务推荐与大厅、服务详情、个人中心、登录注册和企业入驻；保留 V1 首页对比。

- park-client-production.zip：正式静态前端，默认 V2，依赖真实 API；不包含 mock、版本对比或验收面板。
- park-client-preview.zip：本地模拟验收版，左下角切换首页版本，右下角验收工具。

解压后以 index.html 所在目录为站点根目录，并配置 SPA 路由回退，不通过双击 HTML 运行。

图片可在 content/homepage.json 配置。服务商图片和发布信息由服务 API 提供；预览数据位于源码 src/dev/prototype/services.json。文档见项目 README.md、docs/V2_CONTINUATION.md 和 docs/HOMEPAGE_V2.md。

当前未上传远程站点，真实短信、审核、支付及其他业务后台尚未对接。验收版不用于接收真实用户资料。
