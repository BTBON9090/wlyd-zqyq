# 设计语言与维护规范

## 最新客户约束（V2 优先）

以原型商城平台为基础：增加平台宣传专题首页，保留 V1 对比。Banner、服务商品、广告和业务展示必须使用真实图片位，未上传仅纯色缺省，不得绘制矢量图标。V2 可使用完整形象 Banner 和宣传文案，商品陈列仍需紧凑。详细尺寸、图片字段和原型分析见 [第二版首页说明](HOMEPAGE_V2.md)。下方通用规则沿用；与 V2 冲突的 V1 审美判断以客户最新约束为准。

## 第一版设计判断

这是面向企业负责人、行政、财务和园区办事人员的信任型服务门户。设计需要清晰、专业、克制，而非营销活动页或企业内部数据驾驶舱。采用蓝青主视觉、暖色点缀、层叠色面、分层阴影与紧凑业务卡片。首屏同时提供搜索、账号操作、服务分类及精选服务，不能回退为大间距的展示型落地页。

经 2026-09-13 用户反馈修订：视觉变化 5/10，动效 4/10，信息密度 7/10。用户当前任务比平台宣传指标更重要。

## 视觉基础

| 项目     | 规则                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 主色     | `--color-primary`，只用于主操作、选中状态、链接和重点价格                                                    |
| 主色浅底 | `--color-primary-soft`，用于弱提示、类别、主题区域                                                           |
| 文本     | `--color-text` 正文，`--color-text-secondary` 次要说明；重要文本不能用淡灰                                   |
| 状态色   | 成功绿、错误红、提醒褐黄，含明确文字；颜色不是唯一状态线索                                                   |
| 字体     | 系统中文无衬线栈；金额数字自托管 D-DIN Exp（SIL OFL 1.1）。都不从外部 CDN 加载                               |
| 内容宽   | 1360px，宽屏可至 1460px，移动端左右 16px                                                                     |
| 基础字号 | 桌面正文 14px；标题 23–34px，首页主标题 35–39px；卡片标题 15–16px；细节辅助文字 11–12px，可见文字不小于 11px |
| 间距     | 4、8、12、16、20、24、32、40、48、64px；不要随意堆叠间距                                                     |
| 控件     | 默认高度 40px；移动端主要按钮约 43px                                                                         |
| 圆角     | 控件 6px，卡片 10px，表单大块 16px；不将所有东西胶囊化                                                       |
| 阴影     | 按主视觉、卡片、弹窗设置不同强度；柔和投影增加层次，按钮不使用内高光，不堆叠高强度阴影                       |
| 图标     | Phosphor 仅用于功能控件或导航；宣传图片区域禁止绘制 icon，「暂无宣传图」缺省位使用专用 SVG 图标              |
| 动效     | 180–350ms 状态反馈与短距离位移；尊重 reduced motion；Banner 可自动轮换但必须悬停/聚焦暂停，不做滚动劫持      |

分类封面色属于语义辅助色，不等于品牌色；不随主题改变类别含义。不要新增装饰性图表、未经核实的指标或虚构认证徽章。

### 金额数字字体（D-DIN Exp）

- **授权：** Datto, Inc. 以 SIL Open Font License 1.1 发布，保留字体名（RFN）为 `D-DIN Exp`。许可证随字体存放于 `public/fonts/d-din/OFL.txt`，字体文件内亦内嵌完整授权文本。商用、嵌入、再分发都可以，且不可撤销。
- **引用：** 字族变量 `--font-num`（`tokens.css`），`@font-face` 与金额排版层在 `src/styles/fonts.css`；该文件必须在所有业务样式之后导入，否则覆盖不掉各页面既有的 `font-weight`。
- **字重：** 只有 Regular(400) 与 Bold(700)，没有 600。CSS 请求 600 时浏览器按字体匹配规范确定性地落到 Bold(700)，不会产生伪粗体——卡片金额即用这条规则。
- **覆盖范围：** `.price`、`.product-price strong`、`.product-quantity strong`、`.detail-price strong`、`.summary-price`、`.trade-product strong`、`.coupon-amount strong`，以及需要临时统一的通用类 `.num`。
- **边界：** 字体不含中文，单位「元 / 项 / 次」自动回落到 `--font-sans`；数字为**比例字宽**且没有 `tnum` 特性（「1」比其它数字窄约 34%），所以需要上下对齐的表格金额不要使用，密集表格维持系统字体。
- **改动即改名：** 做子集化或修改字形后不得再叫 `D-DIN Exp`（OFL 第 3 条），需另起字体名并在本文件登记。

## 组件规则

- 每个重要区域只有一个明确主操作；返回、修改、继续浏览采用次操作。
- `ServiceCard` 全卡可点击，标题、范围、价格、服务商顺序固定。价格标注参考含义，不能通过按钮暗示已支付。
- 表单标签始终可见，不能只依赖 placeholder。错误定位到字段附近，并让焦点进入首个错误项。
- 同意协议默认不勾选；打开、关闭协议不会自动勾选。
- 对话框使用 Radix。必须提供标题、关闭按钮、Escape 与焦点返回，不能自行复制一个 fixed 遮罩替代。
- 加载、空列表、网络错误、下架、未登录、权限不足和提交成功要有可继续操作的路径。
- 提交成功使用完整结果页。Toast 只做补充，不能作为唯一业务凭证。

## 响应式

- 1024px 以下逐步减少列数，保持输入和操作区域可用。
- 768px 以下服务类别从左侧目录变为水平可滚动导航；详情和申请侧栏改为上下布局。
- 640px 以下主导航折叠；V2 Banner 使用手机图片或桌面裁切，不能隐藏业务宣传图；服务卡保留双列。
- 表单在小屏变单列，长名称允许换行，禁止页面级水平滚动。
- 可滚动类别条保持当前分类明确选中，不能把未展开的分类当成不可用。

## 写作规则

用户需要知道：这是什么、能为我做什么、多少钱、要准备什么、点完会发生什么。

用「申请服务」「提交需求」「等待审核」「返回修改」，少用「赋能矩阵」「全链路闭环」「节点管控」等内部概念。没有真实服务时不能写「AI 已为您匹配」；正式环境的评分、销量与完成率必须来自接口；原型预览可展示对应示例，必须有明确的示例标识。

## 主题交接

主题只通过 `tokens.css` 维护。新增主题时至少检查主按钮文字、主色链接、浅色提示、选中状态与输入焦点的可读性。默认是浅色信任型门户，不自动引入深色模式。新的 AI 或开发者不能换成紫色渐变、深色玻璃或过量大卡片作为另一套设计。

扩展页面的顺序：确认该页面属于已批准范围 → 复用已有壳与组件 → 添加必要业务状态 → 小屏检查 → 记录 API 与实现边界。避免为低风险文案调整增加冗长测试体系。

## 客户明确的风格约束

- 单屏信息密度和办理效率优先，压缩无意义边距、标题区和图片区。
- 页面应有吸引力、层次和色彩活力，避免全站平铺白色卡片。
- 搜索聚焦、卡片悬停、分类切换与弹窗均提供连续反馈；不让持续循环动画干扰业务。
- 不为展示设计感而牺牲真实信息和操作路径。基础语义、表单标签与键盘能力保留，但不以专项无障碍规范主导视觉风格。

## 统一控件与导航（最新）

默认品牌蓝 `#2460d2`；控件高度、圆角、纯色按钮及投影均取自 `tokens.css`。`controls.css` 为全站控件统一层，也覆盖 Radix Portal 弹窗。主操作统一蓝色，不再让首页 Banner 按钮单独使用金色，暖色仍用于 Banner 标题。默认按钮 40px / 6px 圆角，桌面导航 CTA 34px。避免为每个页面创建新的按钮阴影或色值。

顶部主导航高 58px（手机 54px），Logo 两行文字使用独立 line-height 与 1px gap。八项主导航取自 `data/navigation.ts`，除企业服务与个人中心已开发外，其他新增业务专区以空页面保留位置。客户已授权增加导航空页面，前面的试点范围限制不再阻止这些入口。

## V2 跨页延展规范

以 [V2 交接说明](V2_CONTINUATION.md) 为当前状态。主按钮为纯蓝 `#2460d2`，hover 使用纯色 `--color-primary-hover`，禁止恢复渐变按钮。导航选中使用下划线。服务列表宽屏五列、手机两列；相册、详情图片、案例与商家图片均由 ContentImage 承载。个人中心采用左目录与右工作区，不添加虚构待付款订单或数据图表。登录和入驻分开，未登录先验证账号，再回到入驻向导。
