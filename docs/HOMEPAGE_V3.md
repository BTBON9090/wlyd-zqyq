# V3 首页

预览地址：`http://127.0.0.1:5174/?home=v3`。点击现有左下角悬浮按钮，可直接选择 V1、V2 或 V3，选择会保存到本地。未选择过版本时，开发及演示预览默认打开 V3；既有版本偏好仍保留。正式环境保留原默认值，需要启用 V3 时配置 `VITE_HOME_VERSION=v3`。

## 设计与内容

首页围绕平台能力展示组织内容：平台主张、四条能力摘要、运营数据、六大业务、技术方案、客户故事、服务保障与入驻入口。不设置服务搜索和商品挂单区。

参考用户提供的阿里云与千问截图，以浅色底、蓝紫青渐变、通透主视觉、舒展留白与不同模块结构形成节奏。圆角规则为控件 8px、架构节点 10–14px、故事卡片 22px、重点舞台 26–28px。宽度采用 88% 视口比例，超宽桌面继续展开；移动端仅对 V3 首页及其页头做适配。

按钮包含高光掠过、轻微抬升与箭头反馈；内容进入视口时渐入；技术方案切换有淡入。系统开启减少动态效果时禁用动画，并使用即时锚点定位。

## 修改入口

- `src/features/home/HomeV3Page.tsx`：版块组合与交互。
- `src/features/home/homeV3Content.ts`：运营数据、业务介绍、三个技术方案、两组客户故事与服务保障文案。均可独立替换。
- `src/styles/home-v3.css`：V3 独立样式；页头、页脚覆盖通过 `:has(.home-v3)` 限定，不影响其他路由。
- `src/features/home/HomeEntry.tsx`：版本路由、版本偏好与悬浮选择器。
- `public/media/v3/`：页面使用的三张压缩 WebP 图片。
- `design/media/v3/`：三张生成图片的 PNG 原图。

运营数字、客户名称、项目成果与反馈为经用户授权的模拟内容，页面在数据、案例与页尾标注示例。正式替换时需要同时更新案例详情及其统计口径。技术方案是展示性介绍，当前不调用 AI、物流或金融服务接口；保留原导航链接和既有页面业务范围。

## 图片来源与生成提示

三张图片均使用内置 `image_gen` 工具生成，再以 cwebp 转为 WebP；未使用 CLI 图像生成模式。原图与网页图片名称对应。

1. `park-hero`：stylized-concept；政企园区企业服务首页主视觉；浮空白色平台上的玻璃科技园区建筑，绿植与青色连接路径，环绕蓝紫青虹彩玻璃丝带；明亮白色到极浅淡紫背景，精致物理 3D 材质，横向 3:2 构图，无文字、标志、水印或 UI。
2. `customer-campus`：photorealistic-natural；客户故事园区场景；中国现代先进制造园区的斜俯视建筑摄影，银白厂房、玻璃研发楼、绿化庭院、远山和浅蓝天空；明亮自然光，横向 3:2 构图，无文字、标志或水印。图像为虚构场景，不对应真实客户。
3. `ai-sculpture`：stylized-concept；AI 能力主题图；悬于两层透明晶体底座之上的蓝紫虹彩四角玻璃雕塑，折叠曲面、青色反光、珍珠质感、浅淡紫白摄影棚背景；横向 3:2 构图，无文字、标志、水印或 UI 窗口。
