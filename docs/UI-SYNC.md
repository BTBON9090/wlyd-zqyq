# 原型与联调 UI 同步

本原型和联调工程使用相同业务页面、样式及交互。原型保留验收工具、本地示例数据、快速填表与模拟审核；联调工程负责真实接口及跨端业务流转。

当前 UI 来源：`政企园区-集采`，提交 `e2412ba883992ba95a7c2c58a1034d0b9208cb6e`。发布目标仅为 https://zqyq.netlify.app/ 。联调站点、后端与数据库不在此仓库的发布范围内。

## 核对

```sh
npm run ui:check
npm run ui:check -- --source /本机/集采UAT工程
npm run build:preview
```

`docs/ui-baseline.json` 保存联调源码 SHA-256、原型适配文件及原型专有文件的哈希。校验脚本只读来源目录，不会修改联调工程。它会检测联调新增、修改、删除文件以及未登记的原型改动。它不是自动同步任务。

后续联调界面调整后，在原型分支同步对应页面、组件和样式，合并本地演示适配并重新登记哈希；不要反向复制原型目录覆盖联调工程。核对后分别构建、验收、发布两个独立原型。

## 原型适配

- 新个人资料、地址、成员与品牌界面使用原有 UI，并接入本地演示数据。
- 登录、密码修改、头像及成员操作保存在当前浏览器；原型操作不会更新联调账号。
- 采购工作台与订单列表使用同一份本地订单样例，采购和企业服务入口依供应商类型切换。
- 验收工具仍可切换入驻、数据和审核状态；新表单提供演示填入。
- 页面 `/ui-version.json` 标明当前 UI 基线及独立原型模式，便于核查线上是否已更新。
