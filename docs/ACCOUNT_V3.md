# V3 订单展示

V3 订单列表采用独立筛选栏、独立白色订单卡片。卡片依次呈现商家与状态、服务规格、付款明细、操作和订单编号/时间。与企业服务侧栏共用背景、圆角、阴影及选中颜色。

## 接口字段

现有 `GET /account/commerce` 的 `orders` 数组新增以下可选字段，旧响应仍可读取：

- `paymentMode`: `once`（一次支付）或 `installments`（分期支付），缺省显示“按约定支付”，独立于服务验收阶段。
- `discount`: 订单优惠减免金额（人民币元），缺省按 0 处理。
- `payments`: 已完成付款的明细，元素包含 `label`、`amount`、`paidAt`。仅展示接口实际返回的明细，不根据服务阶段推断付款次数。
- `acceptanceDeadline`: 带时区的 ISO 8601 验收截止时间。
- `autoAccept`: 是否约定到期自动确认；仅为 true 时显示相关提示。

`total` 是优惠前总价，`paid` 是累计实付款，`refunded` 是已完成退款金额。优惠后金额 = 总价 − 优惠，待付金额 = 优惠后金额 − 累计实付，净支付 = 累计实付 − 已退款。结清状态按累计实付款判断，部分退款不会重新产生待付款。金额运算以分进行舍入。

倒计时读取截止时间，每秒更新，页面刷新不会重置期限。客户端不在倒计时结束后自行确认验收或执行结算；最终订单状态和到期处理由服务端负责。

本地预览补充了优惠、首期/尾款、验收期限等记录。正式构建仍通过 HTTP 网关获取业务数据，不打包本地记录。
